# Changelog

## v1.1.0

- Renamed to **Training Dashboard**, so it works for any goal event, not just a T100.
- Your goal event's name, set in **Settings → Your goal event**, now appears in the header and section headings. The header distances and the race-distance readiness chart use your event's distances; sports set to 0 are hidden.
- The colour key's "Mock T100 race" is now "Mock race".
- Downloads are renamed `Training-Dashboard-…`. The app now keeps its data in a `TrainingDashboard` folder; if you used an earlier version, your existing `T100Dashboard` folder is still used automatically.

## v1.0.0

- First release: live Garmin dashboard, season plan, coach plan sharing, devices and FTP log, light and dark mode, and downloadable apps.
